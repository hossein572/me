# حسین — پورتفولیوی فارسی و سبک

پورتفولیوی RTL با **React 19، Vite و TypeScript**؛ طراحی روشن، آبی حرفه‌ای، موبایل‌فرست و بدون افکت‌های سنگین.

> **این یک قالب با محتوای نمایشی است.** نام حسین رضایی، پروژه‌ها، مهارت‌ها و رزومه اطلاعات واقعی صاحب مخزن نیستند. پیش از انتشار عمومی، آن‌ها را شخصی‌سازی کنید.

## اجرا

نیازمندی: Node.js 22 یا بالاتر.

```bash
npm ci
npm run dev
```

سرور روی `0.0.0.0:5173` اجرا می‌شود. میزبان پیش‌نمایش Arena (`*.e2b.app`) مجاز است؛ فونت، تصاویر و درخواست‌های مرورگر همگی محلی و هم‌مبدأ هستند.

```bash
npm run build       # بررسی TypeScript و ساخت dist
npm run preview     # نمایش نسخهٔ production روی پورت 4173
```

برای استقرار، محتوای `dist/` را روی یک میزبان استاتیک در ریشهٔ دامنه قرار دهید (مانند Vercel، Netlify یا Nginx). دستور build برابر `npm run build` و پوشهٔ خروجی `dist` است. برای استقرار زیرمسیر، علاوه بر `base` در Vite، مسیرهای عمومی تصاویر، فونت و رزومه را نیز تغییر دهید.

## امکانات

- هدر چسبان، منوی موبایل، تشخیص بخش فعال و ناوبری با صفحه‌کلید.
- Hero با تصویرسازی CSS و SVG سبک، بدون Canvas، ویدیو یا کتابخانهٔ انیمیشن.
- فیلتر پروژه‌ها و پنجرهٔ جزئیات با `React.lazy`، native `dialog`، مدیریت فوکوس و بستن با Escape.
- سه پیش‌نمایش WebP اختصاصی؛ بارگذاری تنبل و ابعاد مشخص برای جلوگیری از جابه‌جایی صفحه.
- کارت‌های Frontend، Backend، UI/UX و DevOps، دربارهٔ من و رزومهٔ قابل چاپ/PDF.
- فرم تماس با اعتبارسنجی، پیش‌نمایش، لینک ایمیل کدگذاری‌شده و امکان کپی متن.
- فونت متغیر **وزیرمتن** به‌صورت self-hosted؛ بدون درخواست به Google Fonts یا سرویس خارجی.
- انیمیشن ورود ۵۰۰ میلی‌ثانیه‌ای با `IntersectionObserver`، بدون scroll listener و با احترام به `prefers-reduced-motion`.
- تست دسترس‌پذیری، خوانایی، حداقل ارتفاع ۴۸ پیکسل برای کنترل‌ها و نبود اسکرول افقی.

## شخصی‌سازی

| مورد                                   | مسیر                 |
| -------------------------------------- | -------------------- |
| نام، ایمیل و اطلاعات پروژه‌ها          | `src/data.ts`        |
| متن معرفی، مهارت‌ها، برند و دربارهٔ من | `src/App.tsx`        |
| رنگ‌ها، فاصله‌ها و breakpointها        | `src/styles.css`     |
| تصویر پروژه‌ها                         | `public/images/`     |
| عنوان، توضیحات SEO و Open Graph        | `index.html`         |
| رزومهٔ قابل چاپ                        | `public/resume.html` |
| آیکون سایت                             | `public/favicon.svg` |

پروژه‌ها **کانسپت نمایشی** هستند و دمو یا سرویس تجاری واقعی ندارند. این موضوع در پنجرهٔ جزئیات مشخص شده است. رزومه نیز نمونه است؛ خروجی PDF از پنجرهٔ چاپ مرورگر دریافت می‌شود.

### فرم تماس، بدون ادعای ارسال سروری

این مخزن backend، API ارسال ایمیل یا ذخیره‌سازی اطلاعات ندارد. فرم ابتدا پیش‌نویس می‌سازد؛ کاربر با «باز کردن ایمیل» آن را در برنامهٔ ایمیل خود ارسال می‌کند، یا متن را کپی می‌کند. هیچ پیام موفقیت جعلی برای ارسال نشان داده نمی‌شود.

آدرس `hello@example.com` یک **placeholder رزروشده** است، نه صندوق دریافت واقعی. آن را در `src/data.ts` و `public/resume.html` جایگزین کنید و یادداشت نسخهٔ نمایشی فرم را پس از تنظیم اطلاعات واقعی ویرایش کنید. برای ارسال مستقیم وب، یک endpoint امن سمت سرور با rate limiting و اعتبارسنجی اضافه کنید؛ هیچ کلید محرمانه‌ای را در کد مرورگر قرار ندهید.

## تست

```bash
npx playwright install --with-deps chromium
npm run build
npm test
npm run format:check
npm audit
```

مجموعهٔ Playwright شامل **۱۵ تست** است:

- چیدمان RTL، تصاویر، متن‌های اصلی حداقل ۱۶ پیکسل و کنترل‌های حداقل ۴۸ پیکسل در عرض‌های **۳۲۰، ۳۷۵، ۴۳۰، ۷۶۸، ۱۲۸۰ و ۱۴۴۰**.
- فیلتر هر گروه پروژه، بارگذاری تنبل جزئیات، Escape و بازگشت فوکوس.
- باز/بسته شدن منوی موبایل با انتخاب لینک، Escape و کلیک بیرون.
- اعتبارسنجی فرم، رد پیام خالی، متن ایمیل و کپی در کلیپ‌بورد.
- باز شدن رزومه، کاهش حرکت و نبود خطای JavaScript یا درخواست خارجی.
- بررسی axe برای WCAG A/AA در موبایل، دسکتاپ و پنجرهٔ جزئیات.

GitHub Actions پس از push و در Pull Request، فرمت، build، تست‌های مرورگر و audit وابستگی‌های runtime را بررسی می‌کند. امتیازهای Lighthouse و محدودیت‌های اندازه‌گیری در [`docs/quality.md`](docs/quality.md) ثبت شده‌اند.

## عملکرد

- جاوااسکریپت اولیه حدود **۸۱ کیلوبایت gzip**؛ جزئیات پروژه در chunk جداگانه.
- مجموع سه تصویر WebP حدود **۷۶ کیلوبایت**.
- بدون analytics، CDN زمان اجرا، ردیابی کاربر یا کتابخانهٔ افکت سنگین.
- فونت‌های ضروری preload می‌شوند؛ انیمیشن‌ها فقط روی opacity و transform هستند.
- هدف Lighthouse موبایل بالاتر از ۹۰؛ نتیجهٔ نهایی به میزبان، کش، شبکه و دستگاه بستگی دارد.

## تولید دوبارهٔ تصویرهای نمونه

تصاویر محصول متعلق به همین قالب هستند و با HTML/CSS و SVG تولید شده‌اند؛ عکس استوک یا فایل طراحی شخص ثالث استفاده نشده است.

```bash
npx playwright install --with-deps chromium
npm run assets
```

اسکریپت `scripts/generate-previews.mjs` خروجی WebP بهینه می‌سازد. Playwright، sharp، Lighthouse و Chromium فقط وابستگی توسعه‌اند و وارد bundle مرورگر نمی‌شوند. برای محیط‌های sandbox بدون دانلود Playwright، پیکربندی اختیاری `USE_BUNDLED_CHROMIUM=1` از Chromium بسته‌بندی‌شده استفاده می‌کند؛ کتابخانه‌های سیستمی Chromium همچنان باید در دسترس باشند.

فونت وزیرمتن با مجوز OFL ارائه شده؛ متن مجوز در `public/fonts/OFL.txt` قرار دارد.
