شرایط: Lighthouse **13.5.0**، حالت موبایل 412×823، DPR برابر 1.75، throttling شبیه‌سازی‌شده، CPU چهار برابر کندتر و RTT برابر 150ms. گزارش نهایی در `2026-09-27T13:01:52Z` تولید شده است.

**محدودیت:** این نتیجه آزمایشگاهی است، نه اندازه‌گیری روی گوشی فیزیکی یا دامنهٔ مستقرشده. تضمینی برای امتیاز ثابت، FPS یا عملکرد همهٔ دستگاه‌ها نیست. زمان پاسخ میزبان، کش، فشرده‌سازی، ترافیک شبکه و مرورگر واقعی می‌توانند نتیجه را تغییر دهند. دادهٔ میدانی Core Web Vitals هنوز وجود ندارد.

باقی‌مانده‌های گزارش: مقداری کد React استفاده‌نشده در بارگذاری اول، فرصت کاهش بیشتر اندازهٔ پیش‌نمایش تصاویر و CSS مسدودکنندهٔ رندر. این موارد با وجود امتیاز ۹۸ پنهان یا غیرفعال نشده‌اند.

### تکرار اندازه‌گیری

```bash
npm run build
npm run preview

# در ترمینال دوم؛ نیازمند Chrome نصب‌شده است
npx lighthouse http://127.0.0.1:4173 \
  --chrome-flags="--headless" \
  --only-categories=performance,accessibility,best-practices,seo \
  --output=html \
  --output-path=.artifacts/lighthouse.html
```

در محیط sandbox از Chromium توسعه استفاده شد. گزارش‌های کامل، screenshotها، browser trace و خروجی build عمداً در Git قرار ندارند؛ مسیرهای آن‌ها در `.gitignore` ثبت شده است.

## حجم خروجی

خروجی `vite build` پس از minify:

| فایل                      |       خام |     gzip |
| ------------------------- | --------: | -------: |
| JavaScript اولیه          | 264.26 kB | 80.98 kB |
| CSS                       |  42.92 kB | 10.04 kB |
| جزئیات پروژه (lazy chunk) |   2.17 kB |  1.08 kB |

سه تصویر WebP در مجموع حدود ۷۶ کیلوبایت هستند. دو subset فونت متغیر محلی حدود ۸۱ کیلوبایت حجم دارند و preload می‌شوند. همهٔ ابزارهای تست، ساخت تصویر و Lighthouse فقط وابستگی توسعه‌اند.

## بررسی عملکردی و دسترس‌پذیری

**۱۵ تست Playwright پاس شدند.**

- عرض‌های 320، 375، 430، 768، 1280 و 1440 پیکسل: بدون اسکرول افقی در تمام بخش‌ها.
- متن‌های اصلی حداقل 16px و کنترل‌های قابل مشاهده حداقل 48px ارتفاع.
- تصاویر با فرمت WebP، `loading="lazy"` و نسبت ابعاد از پیش مشخص.
- فیلتر پروژه‌ها، lazy loading پنجرهٔ جزئیات، بستن با Escape، بازگشت فوکوس و قفل اسکرول.
- منوی موبایل، لینک‌ها و فرم تماس شامل اعتبارسنجی و کپی پیش‌نویس.
- بارگذاری رزومهٔ محلی، `prefers-reduced-motion` و نبود درخواست خارجی یا خطای JavaScript.
- axe: بدون violation در مجموعهٔ قواعد WCAG A/AA انتخاب‌شده، در عرض‌های 375 و 1280 و پنجرهٔ جزئیات پروژه.
- Lighthouse: امتیاز 100 در Accessibility؛ نام قابل‌دسترس برند با متن نمایان یکسان است.

بررسی خودکار جای تست انسانی با screen reader و دستگاه واقعی را نمی‌گیرد.
